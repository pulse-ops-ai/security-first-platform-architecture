## Files added

### New standard

- `standards/diagramming-conventions.md` — workspace visual vocabulary: trust-zone colours (Z0–Z4 fixed fills), layer ribbons (L1–L8 stroke colours), agent-as-client lane (dashed grey, ADR-0002 enforcement), deviation marker (red dashed border + `DEV-NNN` callout), envelope-crossing glyph (signed arrow at Z3→Z4), file-location convention (`architecture/diagrams/` and `docs/diagrams/`), naming convention (lowercase-hyphenated, scope-prefixed), source-of-truth citation requirement, drift-mitigation mechanisms, anti-patterns.

### New canonical skill: drawio

- `.agents/skills/drawio/SKILL.md` — frontmatter (`name: drawio`, description trigger covering common diagram intents and the `.drawio` / drawio / draw.io terms). Body: Procedure (7-step flow: generate XML → write file → optional postprocess → optional export → open → footer citation → INDEX update), Output, format selection, CLI location detection per platform (WSL2 / macOS / Linux native / Linux headless / Windows), export commands, headless ARM64 + x86_64 patterns, known quirks, fallback to drawio MCP, XML structure reference, edge-routing reference pointer, troubleshooting, XML well-formedness rules.

Load on demand.
- `.agents/skills/drawio/references/x86_64-install.md` — install paths for `.deb` / `.rpm` / AppImage on x86_64 Linux + macOS + Windows + headless x86_64 server / CI. Smoke test. Failure-modes table. Load on demand.

## Contract changes

**No contract changes.** This PR is purely additive:

- No existing standard is modified.
- No existing skill is modified.
- No layer responsibility changes.
- No security-boundary changes.
- No template changes (consumer template is unchanged; a follow-up may suggest a `docs/diagrams/` folder).

The new standard introduces *conventions* (visual vocabulary), not *rules* (in the contract-enforcement sense). Anti-patterns are advisory. No CI gate fails because a consumer has not adopted diagramming.

## Cross-repo migration steps

None — `completion_state: architecture-complete`. Consumers may adopt the skills and conventions at their next routine architecture_ref bump. No forced migration.

## Rollback

Each piece is independently reversible:

- Revert `standards/diagramming-conventions.md` → no consumer is affected (none is yet using it).
- Revert one or both skills → no consumer is affected.
- Revert vendor shims → sync-agent-skills check would warn (canonical without shim) but not error.
- Revert slash commands → harmless; warnings only.

No rollback is irreversible.
