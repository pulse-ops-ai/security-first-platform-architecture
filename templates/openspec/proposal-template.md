- **Target decision date:** YYYY-MM-DD

## Problem

What is forcing this change? Describe the friction, gap, or incident. Be specific.

## Proposed change

State the change in one paragraph. The reader should be able to repeat it back.

## Alternatives considered

For each serious alternative:

- **Name.**
- **Why considered.**
- **Why not chosen.**

A proposal with no alternatives is incomplete.

## Impact

- **Repos affected:** list the consuming repos.
- **Layers / profiles affected:** which control layers and which profiles.
- **Standards affected:** which `standards/*.md` files change.
- **Templates affected:** which templates change.
- **Cross-repo contracts:** envelope claims, API shapes, observability schema, etc.

## Migration plan

How do existing consumers move to the new state? Steps, ordering, deadlines.

## Approval

- **Required reviewers:** platform team + leads from each affected consuming repo.
- **Decision rule:** consensus among required reviewers, or platform lead tiebreaker for Tier 3.

## Linked artifacts

- `change.md` — concrete change spec
- `tasks.md` — execution plan
- ADRs that will result
- Dependency records that will result
