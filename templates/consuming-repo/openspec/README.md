# openspec/

> **Template.** Replace with the actual content when you copy into a consuming repo.

This directory holds **OpenSpec** proposals for governed changes in this repository.

A change requires an OpenSpec proposal when it modifies an architecture document, a standard, a template, or a cross-repo contract. See the architecture repo's `team-os/openspec-policy.md` for the full policy.

## Layout

```
openspec/
  README.md
  proposals/
    YYYY-MM-DD-short-title/
      proposal.md
      change.md
      tasks.md
  archive/
    YYYY-MM-DD-short-title/   # completed proposals
```

## Creating a new proposal

1. Create a directory `proposals/YYYY-MM-DD-short-title/`.
2. Copy the templates from the architecture repo's `templates/openspec/` into it.
3. Fill in problem, proposed change, alternatives, impact, migration, and approval.
4. Open a PR.
